# VOID DESPAIR

[![Jogue Agora](https://img.shields.io/badge/JOGAR-AGORA-blueviolet?style=for-the-badge&logo=github)](https://leosdc.github.io/void-despair/)

**Void Despair** é um jogo arcade de sobrevivência frenético desenvolvido como uma peça promocional para o personagem **Damien Kael**, do sistema de RPG **Lyra the Wise**.

## 🌌 O Jogo

Enfrente a fome além do véu. No papel de Damien Kael, você deve sobreviver a ondas implacáveis de projéteis cósmicos em uma dança de partículas e reflexos.

### Características
- **Mecânica de Escudo Dinâmico**: Recrute partículas do ambiente para formar sua defesa.
- **Sinfonia do Vazio**: Gameplay sincronizado com a trilha sonora original de Damien Kael.
- **Ranking Global**: Registre sua sobrevivência no ranking persistente via Firebase.
- **Estética Cyber-Dark**: Visual minimalista com efeitos de neon e glassmorphism.

## 🕹️ Controles

- **Mouse**: Move o núcleo vital (seu cursor).
- **Botão Esquerdo (Hold)**: Ergue o Escudo de Partículas (consome energia).
- **Botão Direito**: Dispara um Pulso Defensivo em direção ao centro.
- **Objetivo**: Destrua projéteis inimigos e sobreviva o máximo de tempo possível.

## 🛠️ Tecnologias

- **Linguagem**: Vanilla JavaScript (ES6+).
- **Renderização**: HTML5 Canvas API.
- **Backend**: Firebase Firestore (Ranking em tempo real).
- **Estilização**: CSS3 com foco em performance e animações fluidas.

## 🚀 Como Jogar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Leosdc/void-despair.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. (Opcional) Utilize um servidor local (como Live Server do VS Code) para melhor performance de carregamento de áudio.
